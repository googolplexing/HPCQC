## How to reproduce from a clean checkout
1. Build the env; `export SINGULARITYENV_PYTHONPATH="$HPCQC_ROOT/src"`.
2. Run the two Piece-2 single sweeps + the harness (commands above) → regenerates
   `results/F5A-VALIDATION-PROVENANCE.md/.json`; expect composition PASS 3.315×,
   cal-tracking PASS z≈60.7.
3. Run the Piece-3 unit suite (11 passed), the single + multi sweeps, the three
   byte-identity diffs (all empty), and the flag query (True@1 / False@2).
All sweeps: 10 seeds × 40 kicks × 1000 shots, autocorr observable, cal 08c3c70f.
Seeds are deterministic (resolve_instance_seed(master_seed, seed)); placement does
not enter the seed, which is why the multi subtrees are byte-identical to the
isolated single runs.
